# THULIRVA E-Commerce Website & Admin Console

Pure, natural farm-fresh milk, bilona cow ghee, artisanal paneer, cold-pressed oils, and farm agro products.

## Structure
- `/website` - Customer e-commerce storefront (Home, Shop, Cart, Checkout, Subscriptions, Recipes)
- `/admin` - Management Dashboard, Products, Orders, Subscriptions, Customers, Delivery Locations
- `/server` - Express API backend server (delegates to shared backend)

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript (Vanilla ES6)
- Backend: Node.js, Express, PostgreSQL
- Assets: HD product photography, vector illustrations, Leaflet maps
